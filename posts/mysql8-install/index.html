MySQL8 安装

2023-03-08分类
  • MySQL
标签
  • #MySQL

OS：OpenCloudOS 8.6（兼容CentOS 8） 安装方式：使用yum安装MySQL8

安装MySQL Yum仓库

去MySQL Yum Repository下载需要的yum仓库

#wget https://repo.mysql.com//your-mysql-yum-repository.rpm
wget https://repo.mysql.com//mysql80-community-release-el8-4.noarch.rpm

然后安装下载好的yum仓库

rpm -ivh mysql80-community-release-el8-4.noarch.rpm

安装MySQL Server

yum install -y mysql-server

启动MySQL

  1. 在Linux机器启动MySQL服务端，并以后台的形式运行
# 启动MySQL Server服务
systemctl start mysqld.service
  1. 查看MySQL Server服务的状态
# 查看MySQL Server服务的状态
systemctl status mysqld.service

如果看到 Active: active (running)说明MySQL服务端后台启动成功 3. 查看MySQL启动时生成默认密码

# 不同MySQL版本，可能路径有一点不同
grep "password" /var/log/mysql/mysqld.log
  1. 连接到MySQL服务端
# mysql默认创建的用户名是root
# 如果上一步看到的默认密码是空，直接不输入密码回车就好
mysql -uroot -p
  1. 修改默认密码
ALTER USER 'root'@'localhost' IDENTIFIED BY 'new password';
